# **App Name**: Teacher's AI Assistant

## Core Features:

- AI Reply Generation: Generates empathetic and professional replies to parents' messages using AI.
- Message Input and Processing: Provides a simple interface for teachers to copy and paste parent messages and generate replies.
- Reply Copy: One-click button to copy the generated reply for immediate use.
- Scenario Selection: Ability to choose different scenarios (e.g., child injury, conflict) to tailor the AI's response using a tool.

## Style Guidelines:

- Primary color: Soft lavender (#E6E6FA) to inspire a sense of calm and trustworthiness.
- Background color: Light grey (#F0F0F0) for a clean and professional look.
- Accent color: Gentle blue (#ADD8E6) for interactive elements and important information.
- Clear and professional font choices for readability, suitable for both teachers and parents.
- Use simple, intuitive icons for easy navigation and understanding.
- Clean and organized layout to streamline the message processing and reply generation.
